## First AI Agent

First AI Agent is my first practical project involving artificial intelligence and large language models. It is written in Python and communicates with an AI model through the OpenRouter API.

The main purpose of this project is to understand how AI-powered applications work behind the scenes. During development, I am learning how to send requests to an AI model, process its responses, manage API keys securely with environment variables, handle errors, and organize the application using clean and maintainable Python code.

The project will gradually evolve from a simple AI request into an agent capable of receiving a task, creating a plan, selecting tools, processing results, and producing a final response.


* Working with external APIs in Python
* Understanding prompts and model responses
* Protecting API keys with environment variables
* Designing maintainable Python applications
* Implementing robust error handling
* Writing tests without making real API requests
* Understanding the basic architecture of AI agents
* Using Git and GitHub during development

This is a learning project and will be expanded step by step as my knowledge of Python, APIs, and AI agent architecture grows.
